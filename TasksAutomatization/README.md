# Tasks Automatization

This is a repository that aims to explore applications with different topics of Python.

## Content

- [AutoReport](/TasksAutomatization/AutoReport/): Based on the [Frank Andrade Project for Auto Market Report](https://www.youtube.com/watch?v=PqiwVp53ftU&list=PLxYZ6JuFZuoYsbJuR_ukb0w1Yz4HlUq_c&index=10&t=1037s) to resume the info on the supermarket sales.

- [ExcelAutomatization](/TasksAutomatization/ExcelAutomatization/) Based on the [Data Science Project Tutorial for Excel Automation](https://youtu.be/JL9RMCS4Sho?list=PLxYZ6JuFZuoYsbJuR_ukb0w1Yz4HlUq_c) to relate the info of a Excel report.
