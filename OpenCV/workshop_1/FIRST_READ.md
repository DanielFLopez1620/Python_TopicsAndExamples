## Version:
This workshop works with python 3.8, so make sure your path and language configuration is related to this version.

## Recommendations:
In the video it is recommended to use PyCharm as IDE, but this workshop was made using Visual Studio Code while working on the root of the repository: 'Python_TopicsAndExamples'. So many programs are linked to this relative path as they use resources of folders linked using the workplace path or taking advantage of the 'path_helps.py" script to generate correctly the path for the OS you are working on.
