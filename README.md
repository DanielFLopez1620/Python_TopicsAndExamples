# Python | Topics and Examples

This is a repository about Python, where the author aims to practice and explore more about this language by using courses, books and resources found on internet that are shared on the proper sections.

## Contents

- **[Basic Python:](/BasicPython/README.md)** A introductory course of Python made by [Platzi](https://platzi.com/home/) in 2022 that aims to cover the basics (variables, operators, conditionals, loops and arrays) to get started with Python. (Finished, pending formatting)

- **[Clean Python:](/CleanPython/README.md)** Covers the lesson learned on the book [Clean Python](https://www.packtpub.com/en-us/product/clean-code-in-python-9781800560215) to write a more Pythonic code. (In Progress)

- **[IntermediatePython:](/IntermediatePython/README.md)** Course centered on teaching about Comprehensions, lambdas, venvs and exception management. It is a [Platzi](https://platzi.com/home/) course. (Finished, pending formatting)

- **[OpenCV:](/OpenCV/README.md)** Collection of resources from workshops and videos that aims to explain about OpenCV and it usage in image processing tasks.

- **[Pandas:](/Pandas/README.md)** Collection of resources from workshops and videos that explains the usage of Pandas.

- **[TaskAutomatizations:](/TasksAutomatization/README.md)** Includes example applications that involve different Python topics on automatization of task, like assistance reports.

## Disclaimer

The purpose of this repository is merely for learning and exploring more about Python. This repository doesn't contains libraries or implementations intended for being deployed or used in real-world applications as it may contains errors, may receive slow updates (varying on the learning time of the author) and may have outdated implementations as not all the resources are intended to be updated.

However, it can be used to explore, learn and review about Python 3.9 and more recent ones.
