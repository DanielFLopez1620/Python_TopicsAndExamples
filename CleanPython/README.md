# Clean Python

Lessons based on the book [Clean Code in Python](https://www.packtpub.com/en-us/product/clean-code-in-python-9781800560215) by Mariano Anaya.
The codes presented were tested on version 3.12.3.

## Content

- [Module 1: Introduction](/CleanPython/m01_code_formatting/README.md): Intro to code formatting, rules and tools for a better Python code.
- [Module 2: Pythonic Code](/CleanPython/m02_pythonic_code/README.md): Presents the usage of magic methods in Python, tips and tricks on implementing custom types, and deepen on iterable, containers and indexes.

## Disclaimer

This codes and notes represents learning interests to explore more about Python, this doesn't intend to be a copy of the book as it includes own codes, comments and additional examples proposed by the author of this repository.
